## Qué se hizo
### #5 — APP_BASE_PATH (hallazgo 1.3)
- `Core\Url::base()` ahora resuelve el prefijo con precedencia: `APP_BASE_PATH` (env) →
  `SCRIPT_NAME`. `Core\Request::capture()` reutiliza `Url::base()` (única fuente) para quitar
  el prefijo del path → fallback robusto para subdirectorios/alias/proxy.

### #6 — session.save_path → storage/sessions/ (hallazgo 1.4)
- `Core\Session::configureSavePath()` apunta `session.save_path` a `system/storage/sessions/`
  (escribible en pools aislados), configurable por `SESSION_PATH`; `resolveSavePath()` es la
  parte pura testeable. `SESSION_LIFETIME` fija `gc_maxlifetime`.
- Dir `system/storage/sessions/.gitkeep` creado; `Deployer` excluye `sessions` del runtime.
- **Bug de hygiene corregido:** el `.gitignore` tenía las rutas de storage mal ancladas
  (`/storage/...` en vez de `/system/storage/...`) → eran reglas muertas. Corregidas + agregado
  `sessions`. Verificado con `git check-ignore`.
- `.env.example`: documentados `APP_BASE_PATH`, `SESSION_PATH`, `SESSION_LIFETIME`.

### #4 — Templates de server + docroot (hallazgo 1.3)
- `docs/deploy/nginx.conf.example` (try_files, bloque php, fix SCRIPT_NAME, deny dotfiles/
  secretos, nota pool aislado), `docs/deploy/apache-vhost.conf.example`, `docs/deploy/README.md`
  (camino dorado + checklist). Regla de oro: **docroot = `system/public`**.

### #7 — deploy:doctor (hallazgo 1.3)
- `App\Services\DeployDoctor::checks()` valida PHP, extensiones, docroot, permisos de
  `storage/*`, `session.save_path`, `APP_KEY`, `.env`, `APP_DEBUG` en prod, rewrite. `ok()`
  respeta severidad (error tumba, warn/info no). Modo `php system/console/deploy.php doctor`.
