Usar para **escribir, revisar, aprobar y cerrar planes de implementación (PL-)** a partir de un
brief y/o roadmap: diseño, fases ejecutables, pseudocódigo, pruebas y rollback.
**Correr con el modelo más capaz y esfuerzo máximo**: acá se toman las decisiones.
SIEMPRE cumple `agentic/methodology/` (incluida `roadmap-brief-plan.md`).
